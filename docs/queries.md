# Rules converted to SIEM queries

Generated by `scripts/build_docs.py` with pySigma. Windows rules use the Sysmon and Windows log-source pipelines; field names may need adjusting to your SIEM's data model.

## Linux Local User Account Created

**Splunk (SPL)**

```spl
Image IN ("*/useradd", "*/adduser")
```

**Elastic (Lucene)**

```text
Image:(*\/useradd OR *\/adduser)
```

## Linux SSH Failed Authentication

**Splunk (SPL)**

```spl
message IN ("*Failed password*", "*Invalid user*")
```

**Elastic (Lucene)**

```text
message:(*Failed\ password* OR *Invalid\ user*)
```

## Linux SSH Brute Force from a Single Source

**Splunk (SPL)**

```spl
message IN ("*Failed password*", "*Invalid user*")

| bin _time span=5m
| stats count as event_count by _time src_ip

| search event_count >= 10
```

**Elastic (Lucene):** not supported by this backend (NotImplementedError). Use the base rule above it plus a threshold alert in the SIEM.

## LSASS Memory Dump via ProcDump or Comsvcs

**Splunk (SPL)**

```spl
Channel="Microsoft-Windows-Sysmon/Operational" EventID=1 (CommandLine="*lsass*" Image IN ("*\\procdump.exe", "*\\procdump64.exe")) OR (CommandLine="*comsvcs*" CommandLine="*MiniDump*")
```

**Elastic (Lucene)**

```text
Channel:Microsoft\-Windows\-Sysmon\/Operational AND (EventID:1 AND ((CommandLine:*lsass* AND (Image:(*\\procdump.exe OR *\\procdump64.exe))) OR (CommandLine:*comsvcs* AND CommandLine:*MiniDump*)))
```
